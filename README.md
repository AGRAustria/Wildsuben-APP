WILDSTUBEN – EINFACHE ANLEITUNG

Was du bekommst:
- index.html = die App
- manifest.webmanifest = wichtig für die Home-Bildschirm-App
- sw.js = sorgt dafür, dass die App nach dem ersten Öffnen auch ohne Internet besser funktioniert

WICHTIG:
Du musst NICHT programmieren.
Du brauchst nur einen Platz im Internet, auf dem die 3 Dateien liegen.
Das nennt man "Webspace".
"HTTPS" bedeutet: Die Internetadresse beginnt mit https://

EINFACHSTER WEG: GITHUB PAGES (KOSTENLOS)

1. Öffne https://github.com/
2. Lege ein kostenloses Konto an, falls du noch keines hast.
3. Klicke auf "New repository".
4. Gib als Namen z.B. wildstuben-app ein.
5. Wähle "Public".
6. Klicke auf "Create repository".
7. Im neuen Projekt: "Add file" → "Upload files".
8. Ziehe diese 3 Dateien hinein:
   - index.html
   - manifest.webmanifest
   - sw.js
9. Klicke unten auf "Commit changes".
10. Öffne im Projekt "Settings" → "Pages".
11. Bei "Build and deployment" bei "Source" "Deploy from a branch" wählen.
12. Bei "Branch" "main" und "/ (root)" wählen.
13. Klicke "Save".
14. Warte ein paar Minuten.
15. GitHub zeigt dir danach eine Internetadresse. Sie beginnt mit https://
16. Öffne diese Adresse auf deinem iPhone in Safari.

APP AUF DAS IPHONE:
1. Öffne die Adresse in Safari.
2. Unten auf das Teilen-Symbol (Quadrat mit Pfeil nach oben) tippen.
3. "Zum Home-Bildschirm" auswählen.
4. "Hinzufügen" tippen.
5. Jetzt erscheint "Wildstuben" wie eine App auf dem Home-Bildschirm.

WENN "ZUM HOME-BILDSCHIRM" NICHT ERSCHEINT:
- Prüfe, dass du die Seite wirklich in Safari geöffnet hast.
- Prüfe, dass die Adresse mit https:// beginnt.
- Lade die Seite einmal neu.
